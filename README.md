# 一摇：Windows / Linux 双色球摇号台

双击 `start.cmd`，浏览器会自动打开。需要 Python 3.10 或更新版本（当前电脑已有 Python 3.14）；不需要 pip、Node.js 或额外库。关闭启动窗口或按 Ctrl+C 停止服务。仅关闭浏览器标签不会停止服务。

也可以运行 `python app.py --open`。默认仅监听 `127.0.0.1:8765`；端口被占用时选择空闲本地端口。页面不加载远程脚本、字体或分析服务，程序仅在更新数据时访问广东福彩官方页面。浏览器记录只存本机。

## 无桌面 Linux 部署

把整个 `ssq-draw-app` 文件夹上传到服务器的普通用户可写目录。需要 Python 3.10+、Bash 4.4+、`flock`（util-linux）和 `nohup`（coreutils），不需要桌面、pip 或 sudo。先检查 `python3 --version`；缺少或版本过低时由管理员按发行版安装。

```bash
cd ssq-draw-app
bash deploy.sh start
bash deploy.sh status
bash deploy.sh logs
bash deploy.sh stop
bash deploy.sh restart
```

无参数执行 `bash deploy.sh` 等同于启动。脚本通过 nohup 后台运行，默认端口8765，日志位于 `.run/server.log`，PID记录位于 `.run/server.pid`。进程身份经过检查后才会停止，端口冲突会报错，不会偷偷选择其他端口。不要在运行时移动目录。可以用 `PORT=18765 bash deploy.sh start` 指定空闲端口；之后重启也要带同样的 PORT。如使用自定义 Python，设置 `PYTHON=/绝对路径/python3`。

在**自己有浏览器的电脑**上建立 SSH 隧道，保持 SSH 窗口打开：

```bash
ssh -N -o ExitOnForwardFailure=yes -L 8765:127.0.0.1:8765 用户名@服务器IP
```

然后在自己电脑浏览器打开 `http://127.0.0.1:8765`。先停止自己电脑上占用8765的程序，或让服务器使用18765并把隧道命令中的两个8765和浏览器端口都换成18765。由于 Host/Origin 校验，本地与远程端口必须一致。服务器不需要桌面，也无需开放8765防火墙端口，只需能通过SSH登录。

当前是私人部署方案，不是公网共享站点；不会自动开放外网、修改防火墙或安装开机服务。nohup 通常可在SSH断开后继续运行，但不会在服务器重启后自启或崩溃后自动恢复，启用了退出登录清理进程的服务器也可能终止它。需要这些保障时应另行配置 systemd。日志追加保存，可在停止程序后按需归档。

Linux 上可运行 `python3 -m unittest discover -s tests -v`，其中包含后台启动、重复启动、停止、重启的集成测试。Windows 环境会跳过该 Linux 专用测试。

## 部署与开发约定（重要）

本项目在公网以**子路径**形式反代部署（例如 `https://<站点>/ssq-draw/`），不是部署在站点根路径。

- **前端（`static/` 下的 HTML / JS）中新增任何请求路径，必须使用相对路径，不能带前导 `/`。**
  - ✅ 正确：`api('api/reroll')`、`fetch('api/state')`
  - ❌ 错误：`api('/api/reroll')`、`fetch('/api/state')`
  - 原因：以 `/` 开头的绝对路径会请求到站点根路径（`https://<站点>/api/...`），绕过子路径反代，导致 404。
  - 同理，`index.html` 里的静态资源引用（`style.css`、`app.js`、`favicon.svg`）也必须用相对路径。
- 后端 `app.py` 的路由保持 `/api/...` 绝对路径不变（反代层会剥离子路径前缀），不要改。
- 后端通过 `SSQ_PUBLIC_ORIGIN` 环境变量放行公网来源的 Host/Origin 校验，`X-App-Token` 校验始终保留；新增后端接口时不要绕过这两项校验。
- 修改后请运行 `python3 -m unittest discover -s tests -v` 并确认全部通过；若在服务器上，重启系统服务（systemd 单元 `ssq-draw.service`）后走公网 URL 回归验证一次。

## 修改号码与自动算奖

摇号结果出来后，每注右侧可以单独点击“修改”，调整6个红球和1个蓝球，也可以点击“重摇”只替换这一行；其它行不会改变。保存或重摇时会保留原始生成号码作为记录，并同步保存到浏览器本地记录。复制和导出使用修改后的号码。

点击“自动算奖”会把当前1-20注和目标期号交给本地服务。目标期尚未有真实开奖时只显示“待开奖”，不会拿上一期号码提前计算；目标期有真实开奖后，才逐注显示命中红球数、蓝球是否命中以及该注的最高奖级，不会兼中兼得。标准奖级识别为：6+1一等奖、6+0二等奖、5+1三等奖、5+0或4+1四等奖、4+0或3+1五等奖、蓝球命中且未达到更高奖级六等奖。

2026年新规则下，“福运奖”只在特别规定期间生效，且3个红球、蓝球未中时才适用。程序默认关闭此项，需根据当期官方公告手动勾选。三等奖、四等奖、五等奖、六等奖和福运奖分别显示固定奖金3000元、200元、10元、5元、5元；一等奖、二等奖显示“浮动奖金”，具体金额必须以当期官方公告为准。规则参考：[中国福利彩票双色球游戏规则](https://www.scflcp.com.cn/yxgz/823145252.jhtml)。

## 随机与权重

- 默认纯随机。每球权重相同；红球6个不放回抽取，蓝球独立抽取。跨注重复允许，不强制凑覆盖数量。
- 使用 `secrets.randbelow` 从操作系统密码学安全随机源获取随机值，不使用时间种子、鼠标轨迹、开奖数据种子或 `random.Random`。系统随机源失败时停止，不回退。依据：[Python 官方 secrets 文档](https://docs.python.org/3/library/secrets.html)。它是操作系统提供的 CSPRNG，不宣称是物理真随机或官方认证的开奖机。
- 微调模式可选，默认最大调整幅度为 ±5%，可调到 0-10%。最近10期与此前10期为两个不重叠窗口，权重为 `10000 * (1 + strength_percent / 100 * (recent - previous) / 10)`，对称四舍五入到整数。较早30期只展示、校验，不参与加权。所有球始终有正权重。
- 红球每次在剩余权重和内取均匀随机整数，再按累计权重抽取并移除。使用 `randbelow` 避免简单取模引入偏差。
- ±5%是单球权重上限，不是最终入选概率上限，更不是中奖概率提升。上限和规则是人工选号偏好，没有经过独立预测验证。纯随机更便于解释；更安全的随机源也不会增加彩票中奖概率。
- 批次ID和权重快照哈希用于查阅，**不是种子**。不保存内部随机状态，不承诺重放随机抽取。

## 自动更新与失败处理

启动立即抓取真实50期，之后固定每12小时检查一次，页面不提供周期调整。只在程序运行期间更新，不创建 Windows 计划任务、不设置开机自启。网络失败10分钟后重试。

数据来源：[广东福彩50期统计页](https://www.gdfc.org.cn/charts/ssq/indicators.html?period=50)。页面显示最近3期、最后成功校验时间和下次检查时间。校验包含期号、重复期号、数量、球号范围、红球唯一性；拒绝相对已存期号的数据回退。网站自身更新延迟不能完全排除，“校验时间”不是开奖时间或独立认证。

数据无法获取、校验失败或成功校验超过24小时，加权暂停，不静默切换到其他权重、不编造历史。用户仍可主动使用不依赖历史数据的纯随机模式。`data/history.json` 是本地数据缓存；每次微调摇号导出的JSON包含该次完整权重快照。
